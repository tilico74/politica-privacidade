# Política de Privacidade

Este projeto contém um exemplo simples de página de política de privacidade.

## Estrutura
- `index.html`: Página principal com o conteúdo da política de privacidade.

## Como usar
Abra o arquivo `index.html` em seu navegador para visualizar a política de privacidade.

Ou acesse a página publicada em: [https://tilico74.github.io/politica-privacidade/](https://tilico74.github.io/politica-privacidade/)

## Sobre
Este projeto pode ser utilizado como base para a criação de páginas de política de privacidade em sites e aplicações web.
